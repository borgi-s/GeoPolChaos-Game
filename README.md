# GeoPolChaos Game

> A browser-based party game for 2–10 players built in React — geopolitical decision-making scenarios that escalate into deliberate, comedic chaos.

## What this is

GeoPolChaos is a live-session party game where players take turns making diplomatic choices drawn from geopolitical scenarios. Each decision carries chaos and deflection ratings that compound across rounds, driving the game toward increasingly absurd outcomes and an end-game video payoff. It's designed for gatherings where the goal is spectacle as much as strategy — think a cross between a trivia night and a political simulation gone wrong. Built as a side project during the PhD years, it demonstrates full-stack React development, audio/video asset management, and Vite-based tooling outside the physics context.

## Stack

- **Language:** JavaScript (97%), CSS (3%)
- **Framework:** React 19
- **Build tool:** Vite
- **Assets:** background music, in-game audio cues, end-game video sequences
- **License:** GPL-3.0

## How to run

```bash
git clone https://github.com/borgi-s/GeoPolChaos-Game.git
cd GeoPolChaos-Game
npm install
npm run dev        # local dev server (Vite HMR)
npm run build      # production build → dist/
```

Requires Node.js 18+. Works on Windows, macOS, and Linux.
